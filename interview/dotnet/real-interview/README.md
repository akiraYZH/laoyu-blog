# .NET Web API 真实面试 100 题

本题库模拟 junior / intermediate .NET Web API 面试的实际追问方式。每题包含中文口述、继续追问、失分点、完整英文口述和英文追问回答；原目录中的 100 题继续作为知识点速查。

## 题目分布

| 题号 | 主题 | 数量 |
| --- | --- | ---: |
| R001～R025 | C# 与异步 | 25 |
| R026～R055 | ASP.NET Core | 30 |
| R056～R075 | EF Core 与 SQL | 20 |
| R076～R090 | 项目经历 | 15 |
| R091～R100 | Docker 与部署 | 10 |

## 练习方法

先遮住答案，用中文回答 30～60 秒；再回答“继续追问”；最后练习英文版。代码题按照“发现问题 → 最小修改 → 验证方法”作答。
